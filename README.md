# Wildhaven — Wildlife Rescue

一個以瀕危動物救援為主題的英文 3D 探索遊戲。你扮演保護區巡護員，走訪森林、榕樹林、蕨類谷地和海灘，解開障礙，再協助獸醫團隊完成四項救援。

遊戲包含比例自然、配色貼近動物原貌的程序生成 3D 模型、動作與環境動畫。美術採用細緻的風格化表現，並非照片級寫實。所有遊戲程式、模型、材質及聲音均在本地生成或隨專案附上；啟動後不需要網絡，也不需要 `npm install`。

## 開始遊戲

需要支援 **WebGL 2** 的現代瀏覽器。建議先使用桌面版 Chrome、Edge、Firefox 或 Safari；若畫面無法啟動，請確認瀏覽器已開啟硬件加速。

先完整解壓專案，再選擇以下一種方法。

### 最簡單：直接開啟單檔版

雙擊 **`Play Wildhaven.html`**，即可在瀏覽器離線遊玩，無須安裝 Node.js 或 Python。此檔已內含遊戲程式、3D 引擎和樣式。

本地檔案的存檔支援會因瀏覽器而異；移動或重新命名檔案也可能改變存檔位置。若要固定網址、穩定保存進度，請使用以下啟動器。啟動器需要 **Node.js 18 或以上**，或 **Python 3**。

**不要直接雙擊開發用的 `index.html`**：這個版本需要經本地網頁伺服器載入各個程式模組。

### macOS

雙擊 `Start Game.command`。啟動器會尋找 Node.js，再嘗試 Python 3，並在瀏覽器開啟：

[http://127.0.0.1:4173/](http://127.0.0.1:4173/)

如果系統不允許雙擊執行，可在 Terminal 切換至解壓後的 `wildhaven` 資料夾，再執行：

```sh
bash "Start Game.command"
```

啟動器會保留終端機視窗。遊玩期間請保持視窗開啟；結束後按 `Ctrl+C` 停止伺服器。

### Windows

雙擊 `Start Game.bat`。啟動器會先嘗試 Node.js，再嘗試 Python 3，並自動開啟相同網址。遊玩期間請保持命令提示字元視窗開啟；結束後按 `Ctrl+C`。

### 手動啟動：macOS、Windows、Linux

在專案資料夾開啟終端機，使用其中一個命令：

```sh
node server.mjs
```

或使用 Python 3：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Windows 安裝 Python Launcher 的環境也可以使用：

```bat
py -3 -m http.server 4173 --bind 127.0.0.1
```

然後開啟 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。若 `4173` 已被其他程式佔用，可停止之前開啟的遊戲伺服器，或將 Python 命令中的連接埠改成 `4174`，再開啟對應網址。

## 操作與目標

主頁會顯示英文規則和操作方式。按開始按鈕進入保護區，再跟隨任務提示尋找動物。

| 操作 | 按鍵／方式 |
| --- | --- |
| Move — 移動 | `W A S D` 或方向鍵 |
| Sprint — 快步移動 | 按住 `Shift` |
| Look — 轉動視角 | 拖曳遊戲畫面；也可點擊畫面鎖定滑鼠後轉動視角 |
| Change view — 第一／第三人稱切換 | `V` |
| Inspect — 查看附近救援地點 | `E` |
| Map — 保護區地圖 | `M` |
| Field journal — 動物與任務筆記 | `J` |
| Pause — 暫停／釋放滑鼠 | `Esc` |

觸控裝置可用畫面上的方向鍵移動，拖曳場景轉動視角，並使用 **View** 和 **Inspect** 按鈕。**Settings** 可切換畫質、環境音效、視角靈敏度和減少裝飾動畫。

到達動物附近後，按 `E` 查看現場資料。先完成解謎，再按畫面提示選擇照護用品及行動。答案不正確時會提供提示，可以重試，不會傷害動物或扣除生命。

四項任務可以自由安排次序：

- **Tiger — The silent clearing**：讀懂野外紀錄，解開籠鎖，再協助處理前腿傷口。
- **Asian elephant — A place to recover**：排列救援計劃，準備陰涼地方和清潔水源，恢復離開路線。
- **Sunda pangolin — Under the scales**：重現運輸標籤的符號順序，安排安靜環境及專業照護。
- **Hawksbill turtle — Back to the blue**：調整沖洗站閥門，協助專業團隊移除漁網和處理鰭肢傷勢。

完成四項救援即可完成本次探險。按閱讀和探索速度，首次遊玩大約需要 10–20 分鐘；這只是估計，遊戲沒有倒數期限。救援步驟是由受訓團隊執行的遊戲化情節，不是現實野生動物處理指南。

## 進度與重新開始

遊戲會自動把進度儲存在目前瀏覽器的本地儲存空間。使用**相同瀏覽器、相同網址和連接埠**再次開啟，可繼續之前的探險。`localhost` 和 `127.0.0.1` 會被瀏覽器當成不同網址，請固定使用其中一個。

主頁的 **New expedition** 可以重新開始，操作前會要求確認。清除瀏覽器網站資料、使用私人瀏覽模式或切換瀏覽器，都可能令原有進度無法保留。

## 常見問題

- **瀏覽器顯示無法連線**：確認啟動視窗仍然開啟，而且網址使用正確的連接埠。如果瀏覽器比伺服器早開啟，等數秒後重新整理。
- **只有空白畫面或 WebGL 錯誤**：確認使用本地網址而非 `file://`，更新瀏覽器，並開啟硬件加速。
- **畫面較慢**：在 **Settings → Graphics quality** 選擇 **Low**，縮小瀏覽器視窗，並關閉其他正在使用顯示卡的程式。實際流暢度取決於裝置和瀏覽器。
- **滑鼠不能離開畫面**：按 `Esc` 釋放滑鼠；也可使用拖曳方式轉動視角。
- **啟動器找不到 Node.js 或 Python**：安裝其中一個後重新執行，或在已能使用該命令的終端機手動啟動。

## 程式與檢查

`src/` 包含場景、角色模型、救援任務、操作及介面程式；`vendor/` 包含 Three.js 及其授權文件。`server.mjs` 只在本機位址提供靜態檔案。

已安裝 Node.js 時，可執行任務邏輯測試：

```sh
npm test
```

也可不經 npm 執行：

```sh
node --test tests/*.test.mjs
```

測試結果以實際執行輸出為準。動物資料來源和第三方授權見 [CREDITS.md](CREDITS.md)。

開發者如需重新產生單檔版，可先執行 `npm install`，再執行 `npm run build`。這只屬開發步驟，遊玩已附上的版本不需要安裝套件。

瀏覽器整合測試需要 Playwright：先執行 `npm install` 和 `npx playwright install chromium`，在另一個終端機執行 `npm start`，再執行 `npm run test:browser`。也可用 `CHROME_PATH` 指向已安裝的 Chrome，並用 `PLAYWRIGHT_MODULE` 指向既有 Playwright 模組。測試使用 `?test=1` 開啟只供測試的場景定位功能，以直接驗證各救援點；正常遊戲網址不會啟用此功能。
